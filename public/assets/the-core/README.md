A placa é **genérica, com três ventoinhas**, dimensões aproximadas 306 × 130 × 59 mm; não corresponde necessariamente ao formato ou aos componentes de uma Gigabyte Radeon RX 7600 real. Os detalhes de formato, potência, comprimento e consumo não são usados para validar compatibilidade física ou elétrica. A etiqueta no painel do simulador representa a peça selecionada no catálogo educativo, **não a identidade do modelo visual**.

O uso do modelo é restrito à apresentação 3D da GPU. O carregamento mantém a GPU procedural anterior como fallback para indisponibilidade ou falha do GLB, sem prejudicar a montagem educativa, o overclock ilustrativo ou a simulação do Arch Linux.

A biblioteca mantém os arquivos GLB em escala real. O visualizador os adapta à escala relativa do laboratório, sem alegar precisão dimensional da montagem. O código original do simulador continua sendo propriedade do projeto e usa as licenças correspondentes.

Para substituir por uma GPU mais fiel à RX 7600, modele/licencie o GLB apropriado e preserve a integração e os pontos de seleção em \`GpuAsset.tsx\`.
